📖 Справка по DSL и синтаксису
Общие правила
  • Секции: === МИР ===, === ПЕРСОНАЖ ===, === КАМЕРА ===. Комментарии: // текст.
  • Строка = блок: сначала условия, затем команды. Команды блока выполняются последовательно, дорожка ждёт завершения каждой.
  • Условия: [Флаг:Имя] — ждать флаг; [НетФлага:Имя]; [Время>2.5] (также >= < <=).
  • Общие команды: [Ждать:1.5], [ВзвестиФлаг:Имя] (или [Флаг:Имя] после команд), [СбросФлага:Имя].
  • [Флаг:Имя] в начале блока — условие ожидания; после команд — установка флага. [ВзвестиФлаг:Имя] — всегда установка.
Дорожка МИР
  • [Дверь:Кабинет|Коридор|Улица:открыть|закрыть]
  • [Лампа:Стол|Фонарь:вкл|выкл]
  • [Монитор:Ноутбук:вкл|выкл]
  • [Экран:Ноутбук:Ошибка404|Код|Пусто]
  • [Погода:дождь|ясно]
Дорожка ПЕРСОНАЖ
  • [ИдтиК:Точка] — точки: Старт, Окно, Стол, Кофемашина, Улица, Фонарь (возвращает RUNNING, пока идёт).
  • [Скорость:260] — px/сек (по умолчанию 220).
  • [Поза:Стоит|СмотритВЭкран|ПьетКофе|Фейспалм|Машет]
  • [Эмоция:ПарИзУшей|Сердце|Удивление|Вопрос:2] — эффект на N сек.
  • [Сказать:Текст без двоеточий:2] — реплика на N сек.
Дорожка КАМЕРА
  • [СледитьЗа:Герой:Зум:Упреждение] — режим Follow, упреждение взгляда в px.
  • [Наезд:1.6:0.8] — плавно зум до 1.6 за 0.8с.
  • [Фокус:Часы:1.5:0.8] — режим Focus на объект (Часы, Ноутбук, Окно, Кофемашина, Фонарь, Улица).
  • [Кадр:Герой:Голова:1.8:0.6] — крупный план головы героя.
  • [Кат:Улица:0.95] — мгновенный монтажный переход в точку/объект.
✅ Свод функциональных требований (из анализа диалога)
  1. Единый бесшовный мир (Scene Graph) с именованными зонами и опорными точками — без нарезки сцен.
  2. Три параллельных таймлайна: Мир, Персонаж, Камера — в едином виртуальном времени.
  3. Синхронизация через blackboard: флаги и условия ожидания (event-driven, без ручного подбора секунд).
  4. Порядок вычисления дорожек: Мир → Персонаж → Камера (камера видит актуальные координаты).
  5. Умная камера-демпфер: Follow с упреждением, Focus на объект, мгновенный Cut; окно 9:16 (X, Y, zoom).
  6. Детерминированный seek(t): свободная перемотка, пригодность для покадрового рендера.
  7. Два окна из одного источника: видоискатель 9:16 + режиссёрский обзор с рамкой камеры.
  8. Скелетная анимация: походка, позы, эмоции-эффекты, реплики.
  9. Интерактивный мир: двери, лампы, монитор с контентом, погода (дождь).
  10. Редактор команд в UI: правка сценария без изменения кода, валидация с указанием строки.
  11. Плеер: play/pause, сброс, скраббер, таймкод, скорость, цикл; клипы и плейхед на 3 дорожках.
  12. Экспорт: PNG-кадр 1080×1920 и запись видео всего ролика (mp4 при поддержке браузера, иначе webm).
  13. Один HTML-файл, чистый JavaScript + Canvas, работает полностью офлайн.
